# Mindset Channel Prompt

## Goal

Invite signed-in members who have generated at least one report to the StayFlat WhatsApp channel for daily mindset-building tips.

## Rules

- Show the prompt when the member has a saved report or has just generated one.
- Do not require payment.
- Keep this prompt independent from the paid-member Telegram prompt.
- Never stack it over another open dialog.
- “Join the WhatsApp channel” opens `https://whatsapp.com/channel/0029Vb82NvZHFxOzQgAoqn0R` in a new tab and records that the member joined on that browser.
- Closing the prompt or choosing “Not now” hides it for seven days on that browser.
- Use a keyboard-accessible native dialog and the existing StayFlat visual style.

## Copy

- Label: Daily mindset practice
- Heading: Build the mindset behind better trades.
- Body: Join the StayFlat WhatsApp channel for short, practical mindset-building tips delivered daily.
- Primary action: Join the WhatsApp channel
- Secondary action: Not now
